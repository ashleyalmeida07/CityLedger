AI Features
Three AI-Powered Capabilities

Each feature is independently powered by Llama 3.3 and runs every time a complaint is filed or reviewed.

01
🏷️ Auto Category & Severity
Every complaint is automatically assigned a category and severity level the moment it's submitted — no officer input required.
  • 1
    Citizen submits complaint title, description & location
  • 2
    Spring Boot sends text to NVIDIA Llama 3.3 70B API
  • 3
    AI returns Category (e.g. Pothole, Garbage, Water Leakage)
  • 4
    AI returns Severity: LOW / MEDIUM / HIGH / CRITICAL
  • 5
    AI gives a 1-line reason for its decision
  • 6
    Results saved to DB and shown on success screen
02
🔍 Duplicate Complaint Detector
AI checks if a newly filed complaint is semantically similar to an existing open complaint within a 500-metre radius.
  • 1
    Submission GPS coordinates are used to query the database
  • 2
    All OPEN complaints within ~500m radius are retrieved
  • 3
    Llama 3.3 compares new complaint to the existing list
  • 4
    If semantic match is found → duplicateOfId is set
  • 5
    Officer queue shows ⚠ Dup badge on the new complaint
  • 6
    Citizen sees a warning on the success screen
03
📝 Officer Summary Generator
Officers can instantly read a plain-English AI summary of any complaint without reading the full description, saving triage time.
  • 1
    Officer clicks a complaint title in the queue
  • 2
    Side drawer slides in and calls GET /api/complaint/summary
  • 3
    Llama 3.3 reads description and generates 2–3 sentence summary
  • 4
    Summary is cached in aiSummary field in the database
  • 5
    Repeat views use cached result — no extra API call
  • 6
    Category, severity, and AI reason are shown in the drawer
